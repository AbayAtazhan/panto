# Panto

**Автоматический зум для записи экрана.** Бесплатно, открытый код, нативный macOS.

[English](README.md) · [简体中文](README.zh-CN.md)

![Panto demo](docs/demo.gif)

Screen Studio стоит $89. Panto делает то, ради чего его в основном и открывают: плавно
приближает важное в демо.

## Что умеет

- **Пишет экран в нативном разрешении** — без апскейла и мыла. HEVC, 60 fps, ~40 Мбит/с.
- **Системный звук и микрофон** — две дорожки, сводятся при экспорте.
- **Три способа зума**: по кликам, по своему хоткею (по умолчанию `⌥⌘Z`) или и то и другое.
- **Плавающая панель** с кнопками Zoom и Stop — и она **не попадает в запись**.
- **Таймлайн-редактор**: перетаскивать зум-блоки, добавлять по клику на превью, удалять,
  менять силу зума и экспортировать заново.
- Экспорт в H.264 `.mp4`, исходный `.mov` всегда сохраняется. Без аккаунтов, телеметрии и Electron.

## Установка

Скачай `Panto.dmg` из [Releases](../../releases/latest) и перетащи в «Программы».

Или одной командой:

```sh
curl -fsSL https://raw.githubusercontent.com/AbayAtazhan/panto/main/install.sh | bash
```

Panto пока не нотаризован. Если macOS не даёт запустить: правый клик → «Открыть», либо

```sh
xattr -dr com.apple.quarantine /Applications/Panto.app
```

Сборка из исходников (достаточно Command Line Tools):

```sh
git clone https://github.com/AbayAtazhan/panto.git
cd panto
./scripts/make_app.sh
open build/Panto.app
```

## Разрешения

| Разрешение | Зачем | Обязательно |
|---|---|---|
| Запись экрана (включая системный звук) | Картинка и звук | Да |
| Микрофон | Дорожка с голосом | Нет |
| Универсальный доступ | Определять клики для авто-зума | Нет (без него — хоткей) |

После выдачи доступа нужно выйти из Panto и открыть заново — macOS применяет разрешение
только на следующем запуске.

## Как пользоваться

1. Выбери дисплей и способ зума.
2. Нажми красную кнопку: окно скроется, появится плавающая панель.
3. Работай. Когда нужно приблизить — `⌥⌘Z` (или кнопка **Zoom** на панели).
4. Останови запись. В редакторе кликни по кадру, чтобы поставить зум, подвигай блоки, **Export**.

Файлы лежат в `~/Movies/Panto/`.
